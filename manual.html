01

개요 — 텐아르란

텐아르(TEN-AR)는 농작물생산조사 현장 조사원을 위한 모바일 웹 도구 모음입니다. 설치·회원가입 없이 주소만 열면 바로 쓰며, 실측·청취 조사 계산부터 지도 위치 선정, 통계 조회, 자료 저장·엑셀 내보내기까지 한 화면에서 이어집니다.

1.1접속과 설치

  1. 브라우저(아이폰 Safari·안드로이드 Chrome)에서 https://ubaldos00-ship-it.github.io/home/ 를 엽니다.
  2. 홈 화면이 「텐아르(10a) · TEN-AR」 로 열리면 정상입니다.
  3. 자주 쓰면 브라우저의 홈 화면에 추가 로 아이콘을 만들어 두면 앱처럼 바로 실행됩니다.
  4. QR로 공유: 홈 → 개별 조사도구 → QR코드 공유.
이름의 뜻

10a(에이아르, are) 당 생산량을 다루는 도구라서 10a → 텐아르(TEN-AR) 입니다. 이 문서에서 10a 는 1,000㎡(약 302.5평) 기준을 뜻합니다.

1.3꼭 알아둘 공통 규칙

  • 자료는 이 기기에만 저장됩니다. 서버 계정이 아니라 브라우저 로컬 저장을 씁니다. 기기·브라우저가 바뀌면 자료가 따라오지 않습니다.
  • 보안 저장(암호화): 저장 자료는 기기에서 AES-256-GCM으로 암호화되어 보관됩니다(배지로 상태 표시).
  • 백업은 내보내기로: 브라우저 캐시·데이터를 지우면 저장이 사라집니다. 중요 자료는 JSON 내보내기(팀 전달) 또는 엑셀/CSV(집계)로 파일 백업하세요.
  • 계산식은 공식 산식 고정. 화면 표시·정렬·내보내기는 개선되어도 수확량·10a 산식은 바뀌지 않습니다.

03

실측조사 — 실측계산기

📐

현장 실측조사원

A/B포구 선정 + 계통추출 + 10a당 생산량

tonghab.html

포구를 골라 실제로 재고 세어 10a당 생산량을 산출합니다. 논벼는 예상량(낟알수·천립중)과 실수확량을 함께 다룹니다.

3.1① 공통사항 — 작물·필지·날짜

  • 작물 선택(1종): 실측 대상 8종.
    마늘양파감자논벼콩배추무총각무
  • 필지 주소: 직접 입력하거나 옆의 📍 지도 로 지도에서 위치를 찍어 지번을 받아옵니다(지번은 카카오 기준).
  • 층 · 조사구: 층은 2자리, 조사구는 4자리. 입력 후 칸을 벗어나면 1 → 01, 23 → 0023 으로 0이 채워집니다.
  • 조사 날짜. 헤더에는 현재 조사 위치(층·조사구·시군·읍면동·지번)가 표시됩니다.

3.2② 비율 설정 · ③ A/B포구

포구 선정을 위해 1번·2번 비율(가·나·다)을 입력하고, A포구·B포구의 면적·중량(작물별 입력 항목)을 넣으면 계통추출 포기수와 10a당 생산량이 산출됩니다. 지도의 포구도구로 실측한 값을 조사표로 전송할 수도 있습니다(7장).

건조율

마늘·양파는 시도별 건조율이 반영됩니다. 「그 외 시도」는 드롭다운에서 고르면 건조율·전년/평년 대비가 자동 적용됩니다.

3.3논벼 전용 — 10a당 예상량

논벼를 고르면 낟알수 기반 예상량 조사표가 열립니다. 입력·산출 항목:

구분항목설명
포기간격가로 · 세로 (cm)1㎡당 포기수 = ROUND(10000/(가로×세로),1)
포기수A·B 1㎡당 포기수, 평균평균은 소수 둘째자리에서 반올림해 1자리로 표시
이삭수10포기 이삭수합계·평균 자동, 평균에 가장 가까운 포기를 대표주수로 선정
낟알수총낟알수 · 완전낟알수완전립 비율·이삭당 낟알수 자동
천립중g정곡(백미) 기준
결과10a당 예상량공문 산식으로 산출(백미 92.9% 기준)
B포구 3포기 이삭수(선택)

예상량과 실수확량의 괴리 확인이 필요한 조사원만 5번·중심·6번 3포기 이삭수를 입력합니다(본 계산에는 미반영). 두 자리 입력 시 다음 칸 자동 이동, 칸을 누르면 전체 선택되어 바로 교체됩니다.

3.4지도 연동

이삭수 아래 🧭 지도에서 A/B포구 위치(현장모드) 를 누르면, 연결된 핀 위치의 현장모드(GPS·진행방향)가 지도에서 자동으로 열립니다. 반대로 지도에서 포구를 실측해 조사표로 보낼 수도 있습니다.

04

청취조사 — 청취계산기

🎙️

청취조사원

재배면적·수확량 → 10a당 생산량

chungchi.html

농가에게 들은 재배면적과 수확량으로 10a당 생산량을 환산하고, 지역 평년·전년과 비교합니다.

  1. 공통사항: 필지 주소, 층·조사구(2·4자리), 조사일.
  2. 지역·작물 선택: 대구·경북·강원 버튼 + 그 외 14개 시도 드롭다운. 작물은 청취 대상(과수·특작·맥류 등).
  3. 재배면적: 응답자의 평을 입력하면 ㎡로 환산(1평=3.3㎡). 여러 행 추가 가능.
  4. 수확량: 조사자료 A/H로 동적 입력. 맥류는 조곡 기준.
  5. 결과: 수확량합계(kg) ÷ 재배면적(㎡) × 1,000 = kg/10a. 아래에 평년·전년 대비와 지방청별 시도 비교 그래프가 나옵니다.
지방청 비교

지역을 고르면 그 지역이 속한 청의 시도끼리(전국 포함) 비교합니다. 예) 인천 → 전국·서울·인천·경기(경인청).

논벼 이삭수 계산기

🌾

논벼 조사원

10포기 이삭수 → 대표주수

jusu.html

논벼 10포기의 이삭수를 세어 합계·평균을 구하고, 평균에 가장 가까운 대표주수를 뽑습니다. 실측계산기와 같은 방식이라 결과를 그대로 이어 쓸 수 있습니다.

  • 1~10번 포기 이삭수를 입력(두 자리 채우면 다음 칸 자동 이동, 빈 칸 백스페이스는 이전 칸).
  • 합계·평균·대표주수가 자동 표시.
  • 필지 주소는 📍 지도 로 채우고, 잘린 주소는 아래 작은 글씨로 전체 표시.
06

작물별 10a 생산량 조회

📊

전 조사원 · 참고

KOSIS 기준 시도·시군 생산량

graph.html

작물을 고르고 지역을 선택하면 연도별 10a당 생산량을 막대+꺾은선으로 보여줍니다(KOSIS 2021~2025).

  1. 작물 선택 → 지역 선택(최대 8개, 논벼는 24개).
  2. 논벼는 「시도 보기 / 시군별 보기」 토글. 시군별은 6개 권역으로 조회:
    대구경북권강원권서울경기권대전충청권광주호남권부산경남권
  3. 연도별 값·평균·전년/평년 대비를 표와 그래프로 확인.

7.2지번은 카카오 기준

왜 카카오?

브이월드 지적도가 일부 지역(현풍·고령 등)에서 실제와 밀려 있어, 좌표→지번은 카카오 지도 API를 우선 사용합니다(실패 시 브이월드 자동 폴백). 「이 위치에 저장」·「조사표 전송」·계산기 핀 저장 모두 카카오 지번으로 통일했습니다.

7.3조사표로 전송

  1. 포구/측정을 완료하고 저장합니다(저장 안 하면 「저장 후 전송」 안내).
  2. 📤 조사표 전송 을 누릅니다.
  3. 포구는 실측계산기(tonghab), 측정은 청취계산기(chungchi)로 값이 채워지며 화면이 그 계산기로 이동합니다.
  4. 전송 주소는 연결된 저장 핀의 카카오 지번을 씁니다.
08

저장 · 불러오기 · 엑셀

실측·청취 계산기 모두 저장/불러오기 창을 갖습니다. 자료 저장·목록 관리·백업(JSON)·집계·엑셀 내보내기를 여기서 합니다.

8.1저장목록 다루기

  • 새로 저장 / 덮어쓰기 / 불러오기(📂) / 삭제(🗑) / 잠금(🔒). 잠근 자료만 집계·엑셀에 들어갑니다.
  • 조회: 시도·시군구·읍면동·작물 콤보로 걸러 보기.
  • 정렬: 최근 저장순 · 생산량/면적 큰순 · 작물별 · 목록 순서(↑↓).
  • 순서 변경: 「목록 순서(↑↓)」에서 각 항목의 ▲▼로 순서를 바꿉니다(엑셀도 이 순서대로 나옵니다).
  • 목록 항목에는 작물 뒤에 층-조사구(파랑), 주소의 지번(빨강)이 표시됩니다.

8.2작물별 10a당 수량 집계

잠금(🔒)한 자료를 작물별로 묶어 평균 생산량을 보여줍니다. 각 항목은 01-0011 식 층-조사구가 주소 앞에 붙어 표시됩니다.

8.3엑셀 내보내기 (논벼 예상량)

  1. 집계에서 ⬇ 엑셀 저장 또는 ⬇ CSV 저장.
  2. 처음 저장 시 비밀번호를 설정합니다. 이후에는 비밀번호가 맞아야 저장됩니다(🔑로 해제).
  3. 엑셀에는 주소·시도·시군·읍면동·층·조사구·동리·지번(본지번/부지번) + 42개 조사 항목 + 시군별 합계·평균이 들어갑니다.
  4. 엑셀 안에 수식이 들어 있어 값을 고치면 스스로 재계산됩니다.
주의

.xls를 열 때 「형식이 확장자와 다릅니다」 경고가 뜨면 [예]를 누르면 정상적으로 열립니다. 지번은 텍스트로 저장되어 27-2가 날짜로 바뀌지 않습니다.

팀 전달용 백업

집계 엑셀과 별개로, 저장/불러오기 하단의 JSON 공유·내보내기·불러오기는 텐아르끼리 자료를 그대로 옮길 때 씁니다(연결 요도·포구 기록 포함).

관리자 기능

공지와 전광판은 관리자만 수정할 수 있습니다. 관리자 계정으로 로그인하면 모든 사용자에게 반영됩니다(Firestore).

9.1공지 등록·수정

  1. 홈 알림의 🔐 로 관리자(구글) 로그인.
  2. 관리자 바에서 + 공지 추가 → 제목·내용 저장.
  3. 목록의 📌 고정 · ✎ 수정 · ✕ 삭제로 관리.

9.2LED 전광판 수정

  1. 관리자 바의 📢 LED 수정.
  2. 한 줄에 한 문구씩 입력. 링크는 뒤에 |주소, 채팅 열기 줄은 주소 자리에 CHAT.
  3. 전체 반영 저장 → 모든 사용자 전광판에 반영.
관리자 전용

공지·전광판 수정은 지정된 관리자 계정에서만 가능합니다. 저장 값은 모든 사용자에게 동기화되므로 오탈자·링크 주소를 확인 후 저장하세요.
