     · 01012341234 → 010-1234-1234
     · 0541112222  → 054-111-2222
     · 02…         → 02-XXXX-XXXX (서울)
4) 「주소」 → 「메모」로 라벨 변경, 예시도 「연락처 주소」 → 「기타사항」.
