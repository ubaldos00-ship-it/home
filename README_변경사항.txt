하단 「오늘 접속자」 카운트 보정 (실시간 1명인데 오늘 0명 모순 수정)

증상
  - 하단에 「실시간 1명 · 오늘 0명」처럼, 지금 접속자가 있는데도
    오늘 방문자가 0으로 나오는 모순이 있었습니다.

원인
  - 접속 통계는 구글(GA4) 서버값을 받아 표시하는데, GA4의 '오늘' 집계는
    처리 지연이 있어 이른 시각(또는 방문이 적을 때)에는 0으로 돌아옵니다.
    (실시간 접속자는 별도 집계라 정상값 1이 나옴)
  - 화면 코드가 그 0을 그대로 받아 「오늘 0명」으로 덮어써, 실시간보다
    작게(0명) 표시되는 모순이 생겼습니다.
  - ※ 서버(구글 Apps Script/GA4)의 '오늘' 집계 자체는 외부 서버라 이 파일에서
    직접 못 고칩니다. 아래는 화면 표시 보정입니다.

수정 (화면 표시 보정)
  - 오늘 = max(서버 오늘값, 실시간 접속자, 로컬 하한 1) 로 계산해,
    「오늘」이 「실시간」보다 작아지지 않게 했습니다.
      · 서버 오늘값이 0으로 와도 → 실시간(예:1) 이상으로 표시.
      · 서버 집계가 채워지면(예: 오늘 25) → 그 큰 값으로 표시.
  - 로컬 오늘값은 새로고침할 때마다 부풀지 않도록 「이 기기 오늘 방문=1」
    하한만 사용합니다(기존엔 새로고침마다 +1 되던 것 정리).

검증 (브라우저 실제 테스트)
  - 서버 응답 {realtime:1, today:0, total:344, ...} 상황에서
    이전: 실시간 1 · 오늘 0 (모순)
    수정후: 실시간 1 · 오늘 1 (오늘 ≥ 실시간) 확인.
  - 누적(344)·조회수(30,969)는 그대로 정상 표시 확인.
  - JS 문법 검사 통과(node --check, 인라인 스크립트 8개).

참고 (정확한 '오늘' 집계를 원하실 경우)
  - 기기별이 아닌 사이트 전체의 정확한 '오늘 방문자'는 서버(구글 Apps Script,
    GA4 Data API)에서 '오늘' 쿼리를 realtime 기반 또는 시간대(KST) 보정으로
    바꿔야 완전해집니다. 해당 Apps Script를 공유해 주시면 그 부분도 손봐
    드리겠습니다.
