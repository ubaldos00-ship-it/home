[A] 논벼 실수확량 조사표 UI 보완 (엑셀 만들기 전 준비)

   「3줄 예취길이 (cm)」 행 추가 (A포구/B포구) → 그 아래에 3㎡ 포기수(계산),
   3㎡ 예취포기수(실제), 결주 수 순으로 표시.
2) 「포기수 확인」과 「① 조제벼·건조벼·생볏짚 중량」 사이에
   「📋 A·B포구 피해상황·비고」 입력 추가.
   - A포구/B포구 각각 「피해부호 / 피해율」 선택(예상량과 동일 양식·코드).
   - 「비고」 입력란 추가.
   - 실수확량 자체 입력이며, ④ 피해상황 표와 엑셀에 반영됩니다.

────────────────────────────────────────
[B] 논벼 실수확량 엑셀 집계 내보내기 (예상량과 동일 방식)
────────────────────────────────────────
3) 저장/불러오기 → 작물별 10a당 수량 집계 화면에
   「🌾 논벼 실수확량 → 엑셀 집계 내보내기」 바 추가.
   - 기존 「📊 논벼 예상량」 바 아래에 함께 표시.
   - 활성화·보안은 예상량과 동일: 집계 모달 제목(💾 저장/불러오기)을
     5회 연속 탭하면 표시(일부 권한자), 비밀번호는 예상량과 공용.
   - 버튼: ⬇ 엑셀 저장(.xlsx) / 📤 엑셀 공유 / ⬇ CSV 저장 / 📤 CSV 공유.
   - .xlsx는 아이폰(Numbers)·안드로이드(Sheets)·엑셀에서 열립니다.

   컬럼 구성(이미지와 동일):
   - 주소~부지번(A~J)은 예상량과 동일, K는 여백(예취길이를 L열에 맞춤),
     L/M=예취길이(A/B), N부터 실수확량 항목.
   - 입력 셀을 제외한 셀에는 아래 수식이 들어가 파일 자체가 재계산됩니다.
       · 조제벼(1/8) O = N/8
       · 건조율    Q = IF(P="","",P/O)
       · 검산계    S = N+ROUND(N/8,0)+P+R
       · 제현율    X = IF(Z="","",Z/P)
       · 중량총량  Y = SUM(Z:AA)
       · 수분합계  AD = SUM(AB:AC)
       · 수분평균  AE = AD/2
       · 10A생산량 AF = IF(OR(N="",Z=""),"",Z*8/6*(100-AE)/85*0.929)
       · 예상량대비 AG = IF(AF="","",AF/AH)
       · 생산량-예상량 AI = IF(AF="","",AF-AH)
       · 비고 AJ = 실수확량 비고 입력
   - 10A당 예상량(AH)은 저장된 예상량 조사결과에서 자동으로 채워집니다.

────────────────────────────────────────
[C] 필지주소 → 논벼 시군별 비교 '권역·시군' 자동선택
────────────────────────────────────────
4) 필지주소를 입력하면(예: 경상북도 고령군 …) 논벼 시군별 비교의
   권역(대구경북권)·시군(고령군)이 자동 선택됩니다.
   - 주소를 입력하지 않으면 기존처럼 사용자가 직접 선택.
   - 이미 시군을 선택한 경우에는 자동선택이 덮어쓰지 않습니다(수동 우선).
   - 같은 이름의 시군(고성군: 강원↔경남)은 주소의 시도로 구분합니다.
