① 여러 건(예: 24건) 불러올 때 1건이 빠지던 문제
  - 원인: 불러온 항목의 키가 기존 목록과 겹치면 새 키를 만드는데,
    그 새 키가 "현재시각(ms) + 0~999 난수" 였습니다. 24건을 같은 순간에
    처리하다 보니 난수가 겹쳐(생일 문제), 두 항목이 같은 키가 되어
    한 레코드가 다른 레코드를 덮어써 사실상 1건이 사라졌습니다.
    (충돌은 무작위라 매번 다른 번호가 빠져 "왜 4번이 빠지는지" 알기 어려웠음)
  - 수정: 새 키를 "현재시각 + 0~999,999 난수 + 중복검사 반복"으로 만들어
    절대 겹치지 않는 고유 키를 보장. → 어떤 항목도 덮어써지지 않음.

② 불러오면 순서가 반대로 뒤집히던 문제
