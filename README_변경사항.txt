[1] 그래프 데이터 라벨 네모박스 제거
  - 기존: 각 데이터 점의 값이 흰색 네모박스(테두리 포함) 안에 표시되어,
          여러 지역을 함께 볼 때 박스가 다른 선·데이터를 가렸음.
  - 변경: 네모박스를 없애고(backgroundColor 없음·테두리 0·여백 0),
          숫자에 흰색 외곽선(halo)만 입혀 선 위에 바로 표시.
          → 데이터가 여러 개 겹쳐도 가림 없이 숫자가 또렷하게 보임.
