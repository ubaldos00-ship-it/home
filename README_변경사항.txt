[목적] 게임센터 안 개별 게임들에 「뒤로가기」 버튼 추가 + 홈버튼은 게임센터로.
       (두당에서 게임센터를 링크로 열어도, 게임→게임센터→두당 순으로 정확히 복귀)

■ 네비게이션 흐름 (완성형)
  두당/텐아르 ──(링크)──▶ 게임센터(game_center) ──(게임카드)──▶ 개별 게임
     ▲                         ▲                              │
     └──(게임센터 ‹뒤로=출처복귀)┘   └──(게임 ‹뒤로 / 🎮게임센터)──┘
  · 게임 안 「‹ 뒤로」  = history.back (같은 탭이면 게임센터로), 없으면 game_center.html
  · 게임 안 「🎮 게임센터/🏠」 = 항상 game_center.html (홈=게임센터)
  · 게임센터의 「‹ 뒤로」 = 두당/텐아르(들어온 곳)로 (v225에서 적용)
  ※ 어느 게임도 텐아르 홈으로 '직행'하지 않음 → 두당에서 열려도 텐아르로 안 튐

■ 게임별 적용
  1) 매의 눈(game_eagle_eye)   : 헤더 왼쪽에 ‹ 뒤로가기 추가 (🏠=게임센터 유지)
  2) 작물퀴즈(game_crop_quiz)  : 헤더 왼쪽에 ‹ 뒤로가기 추가 (🏠=게임센터 유지)
  3) 사다리게임(ladder)        : 헤더 「🏠 홈(→텐아르 직행)」 제거 → 「‹ 뒤로」로 교체.
                                 「🎮 게임센터」는 유지(홈=게임센터).
  4) 작물홈런왕(baseball)      : 시작화면에 「‹ 뒤로」 + 「🎮 게임센터」 나란히 추가
  5) 작물갤러그(galaga)        : 시작화면 버튼줄에 「‹ 뒤로」 추가(랭킹·게임센터와 나란히)
  6) 작물버블버블(bubble)      : 시작화면에 「‹ 뒤로」 + 「🎮 게임센터」 나란히 추가
