저장: 2026-10-28 02:00 KST

수정 파일: tonghab.html(v160), chungchi.html(v131)

※ 아래 6번(뒤로가기)은 게임센터·PDF센터 파일이라 이 묶음과 별도로 전달합니다.

════════════════════════════════════════
1) 논벼 실수확량 「크기별 중량」 양방향 입력 매끄럽게 (실측)
════════════════════════════════════════
  - 원인: 총량·현미 칸에 「3자리 입력 시 자동 다음칸 이동」이 걸려 있어
    ① 현미 입력 중 설미를 건너뛰고 수분칸으로 튀고, ② 총량 4자리 입력을
    방해했습니다. 또 자동계산이 「입력 중인 칸」까지 덮어써 끊겼습니다.
  - 수정: 총량·현미의 자동점프 제거 + 자동계산이 「지금 타이핑 중인 칸」은
    절대 덮어쓰지 않도록(나머지 칸만 계산). → 총량+현미→설미,
    현미+설미→총량 양방향이 끊김 없이 입력됩니다.

════════════════════════════════════════
2) 설미 30g 이상 → 「내검대상」 경고 (실측)
════════════════════════════════════════
  - 설미(1.6㎜미만)가 30g 이상이면
    「⚠ 설미가 ○○g 입니다. 30g 이상은 내검대상입니다.」 경고를 표시합니다.

════════════════════════════════════════
3) 수분측정 11.0% 이하 / 17% 이상 → 경고 (실측)
════════════════════════════════════════
  - 1회·2회 수분측정값이 11.0% 이하이거나 17% 이상이면
    「⚠ 수분측정값(…)이 11.0% 이하 또는 17% 이상입니다. 재확인하세요.」 표시.

════════════════════════════════════════
4·5) 연락처(이름·주소·전화) 추가 — 실측·청취 공통
════════════════════════════════════════
  - 공통사항의 층/조사구 아래에 「📇 연락처(이름·주소·전화)」 입력란 추가.
  - 저장/복원에 포함(불러오기 시 미저장 자료면 빈칸·잔상 제거, 초기화 반영).
  - 저장/불러오기 목록에서 필지주소(📍) 아래에
    「📇 이름 · ☎ 전화」가 함께 보입니다.
  - 실측(tonghab)·청취(chungchi) 동일하게 적용.

검증 (브라우저 실제 테스트)
  - 양방향: 총량100+현미94→설미6 / 현미90+설미7→총량97, 입력 중 덮어쓰기 없음.
  - 설미 35g → 내검대상 경고 표시. 수분 1회10.0%·2회18.0% → 경고 표시.
  - 연락처 입력→저장수집(_slCollect/_ccCollect)→복원(_apply) 정상, 목록 표시.
  - JS 문법 검사 통과(tonghab 21 · chungchi 12 인라인 스크립트).

(별도 전달) 6) 게임센터·PDF센터 뒤로가기 안정화
