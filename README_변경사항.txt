[버그 수정] 「📎 저장된 조사표에 연결」 목록이 비어 보이던 문제
────────────────────────────────────────
증상
  - 저장핀 → 조사표 선택 → 「📎 저장된 조사표에 연결(권장)」을 눌렀는데
    아무 조사표도 안 보임(빈 목록). 실제로는 실측조사표 저장목록에
    자료가 있는데도 안 나왔음.

원인
  - 실측/청취 저장목록(tonghabSaveList·chungchiSaveList)은 각 계산기에서
    「이 기기 전용 키」로 암호화되어 저장됩니다(보안 저장).
  - 지도(map)는 그 목록 키를 암호화 관리 대상으로 갖고 있지 않아,
    읽을 때 암호문이 그대로 읽혀 목록으로 인식되지 못했습니다(→ 빈 목록).

수정
  - 지도에서 저장목록을 읽을 때, 암호화된 자료면 같은 기기 키로
    자동 복호화(TenarCrypto)해서 목록을 정상 표시하도록 했습니다.
  - 암호화를 쓰지 않는 환경(평문 저장)은 그대로 읽습니다.
  - 이제 핀에서 「📎 저장된 조사표에 연결」을 누르면 실측·청취에
    저장된 조사표 목록이 보이고, 골라서 연결할 수 있습니다.

검증
  - 저장목록을 기기 키로 암호화 → 지도에서 같은 키로 복호화해서 다시
    목록(2건)으로 읽어오는 왕복 동작 정상 확인(브라우저 실제 테스트).
  - JS 문법 검사 통과(node --check).
  - ※ 실제 기기에서 「📎 저장된 조사표에 연결」을 눌러 목록이 보이는지
    최종 확인을 권장합니다.
