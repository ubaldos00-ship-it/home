════════════════════════════════════════
논벼 실수확량 조사표에 「🌾 수분 기준 역산」 추가
════════════════════════════════════════
위치
  - 논벼 실수확량 조사표의 10a당 수량(백미) 결과 아래(제현율·현백률 다음)에
    「🌾 수분 기준 역산」 영역을 새로 넣었습니다.

동작
  - 위에서 계산된 10a당 수량(백미)을 그대로 「고정(🔒)」합니다.
    (수분을 바꿔서 수량을 다시 계산하는 기능이 아님 — 수량은 바뀌지 않습니다.)
  - 화면에 자동으로 표시:
      · 계산된 10a당 수량 🔒  (예: 884 kg/10a)
      · 실제 수분            (예: 18.20 %, 1회·2회 평균)
      · 실제 1.6㎜ 이상      (예: 742 g, 입력한 현미 중량)
  - 사용자가 「기준 수분」만 입력합니다(기본값 15.0%, 직접 수정 가능 — 14.5·15.5 등).
  - 그러면 그 기준 수분으로 환산했을 때 필요한
      · 1.6㎜ 이상(현미) 중량
    을 역산해서 큰 글씨로 보여줍니다. (예: 15.0% → 714.1 g)

계산 구조(역산식)
  - 10a 수량은 「1.6㎜이상 현미중량 × (100 − 수분)」에 비례합니다.
    (백미 = 현미 × 8/6 × (100−수분)/(100−15) × 92.9%)
  - 따라서 10a 수량을 고정하면:
        1.6㎜이상 = 실제현미 × (100 − 실제수분) ÷ (100 − 기준수분)
  - 조제벼·건조벼는 백미 10a 수량 산출에 영향을 주지 않으므로
    (조곡·제현율 계산에만 사용) 역산에는 들어가지 않습니다.
  - rsReverseCalc()가 기존 riceRealYieldCalc 끝에서 호출되어, 현미·수분·기준수분을
    바꾸면 자동으로 다시 계산됩니다. 기존 계산 함수 자체는 수정하지 않았습니다.

검증 (브라우저 실제 테스트)
  - 현미 742g·수분평균 18.20%·기준수분 15.0% → 역산 1.6㎜이상 714.1 g 확인.
  - 기준수분 14.5% → 709.9 g, 15.5% → 718.3 g (수분 낮을수록 가벼워짐 = 방향 정상).
  - 역산한 714.1g을 기준수분 15%로 정방향 재계산 시 같은 10a 수량 재현(반올림 ±1kg 내).
  - 10a 수량(🔒)·실제수분·실제현미 자동 표시 확인.
  - 기준수분 기본값 15.0% 표시 및 수정 가능 확인.
  - JS 문법 검사 통과(node --check, 인라인 스크립트 21개).
