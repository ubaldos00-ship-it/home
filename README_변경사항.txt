논벼 조사표 — 포구기점 길이 + 표본구역 선정요도 수정
────────────────────────────────────────
증상
  - 「표본구역(포구)기점 선정」의 A/B 가로·세로 길이가 비어 있었음.
  - 「표본구역 선정요도」 그림이 안 보였음.
  원인: 이 값과 요도는 「A/B포구 계산」을 실행할 때 만들어지는데,
        조사표를 열 때(특히 저장자료 불러온 뒤) 계산이 안 돼 있어 비어 있었음.

수정
  - 조사표(한장 보기)를 열 때 A/B포구 계산을 자동으로 한 번 갱신하도록 함.
    → 아래 값이 통합계산기 결과 그대로 자동 표기됩니다.
       · A 표본구역 가로 길이 = 가~나 길이 × 표본구역 비율(가)  [= A포구 가로기점]
       · B 표본구역 가로 길이 = A포구 가로기점 + 추출간격        [= B포구 가로기점]
       · A 표본구역 세로 길이 = A지점 세로 총길이 × 비율(나)     [= A포구 세로기점]
       · B 표본구역 세로 길이 = B지점 세로 총길이 × 비율(다)     [= B포구 세로기점]
    → 「표본구역 선정요도」에 지도에서 선정한 가-나·AB포구 기점 요도(도형)가
       그려져 표시됩니다.
  - 계산에 필요한 값이 부족하면 조용히 건너뜁니다(에러창·화면 이동 없음).

검증
  - 브라우저 테스트: 가~나 600 / 세로총길이 A250·B248 / 비율 가0.6·나0.5·다0.5 →
       A 가로 360cm, 세로 125cm / B 가로 660cm, 세로 124cm 자동 표기 확인
       (B가로 = 360 + 추출간격 300 = 660).
    조사표 선정요도에 필지·가나다·A/B포구 요도(SVG) 렌더 확인.
  - JS 문법 검사 통과(node --check).

참고
  - 선정요도는 해당 조사(연결 핀)의 가-나·AB포구 선정 데이터를 바탕으로 그려집니다.
    지도에서 A/B포구를 선정하지 않았거나 계산에 필요한 값이 없으면
    "선정요도 없음"으로 표시됩니다.
