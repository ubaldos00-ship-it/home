1) 불러오기 시 「AB포구 계산하기」 이전 결과가 남던 문제 수정
════════════════════════════════════════
증상
  - 빠른실행 → 실측계산기에서 논벼를 불러와 「AB포구 계산하기」를 눌러 계산한 뒤,
    저장하고 다른 목록을 불러오면 이전 자료의 AB포구 계산 결과가 그대로 떠 있어
    (잔상) 헷갈렸습니다.
원인
  - 목록 불러오기는 페이지를 새로 그리지 않는 방식이라, 직전에 「계산하기」로
    표시해 둔 결과 박스가 그대로 남아 있었습니다.
수정
  - 불러오기(복원)가 끝나면 AB포구 결과 박스를 숨깁니다.
  - 따라서 AB포구 결과는 「AB포구 계산하기」 버튼을 누른 그 순간에만 나옵니다.
    (불러온 직후에는 이전 결과가 보이지 않습니다.)

2) 논벼 실수확량 조사표 ②「크기별 중량」 양방향 입력
════════════════════════════════════════
  - 기존: 총량 + 1.6㎜ 이상(현미)을 넣어야 1.6㎜ 미만(설미)이 자동 표시 → 그대로 유지.
  - 추가: 1.6㎜ 이상(현미) + 1.6㎜ 미만(설미)을 넣으면 총량이 자동 표시.
    (이를 위해 「1.6㎜ 미만(설미)」 칸을 입력 가능한 칸으로 바꿨습니다.)
  - 두 방향 모두 동작: 총량이 비어 있을 때만 현미+설미로 총량을 채우고,
    총량이 있으면 기존처럼 총량−현미로 설미를 보여줍니다.

════════════════════════════════════════
  - 합계가 정수여도 「30.」 또는 「30 %」가 아니라 항상 「30.0 %」처럼
    소수점 첫째자리까지 표시되도록 했습니다.

4) 논벼 전용 「바로가기 책갈피」 추가 (난수표 조회기 스타일)
════════════════════════════════════════
  - 논벼를 선택하면 화면 오른쪽에 빨간 「◀ 바로가기」 책갈피 탭이 나타납니다.
  - 탭(화살표)을 누르면 옆으로 튀어나오며 두 개의 버튼이 보입니다.
      · ⬆ 맨 위로 — 화면 맨 위(①공통사항)로 이동
      · 🌾 실수확량 조사표 — 논벼 실수확량 조사표로 바로 이동
  - 불러오기 후 실수확량까지 많이 내려가야 하는 불편을 줄였습니다.
    (논벼가 아닐 때는 책갈피가 보이지 않습니다.)

  - 크기별 중량: 총량+현미→설미, 현미+설미→총량 양방향 정상 동작 확인.
  - 수분 합계 30 → 30.0 % 표시 확인.
  - 책갈피: 논벼에서만 표시, 탭으로 열림/닫힘, 맨 위로·실수확량 조사표 이동 확인.
