[2] 게임센터 — 게임 안의 "게임센터/홈" 버튼 이동 방식 수정
    (game_crop_baseball / game_crop_bubble / game_crop_galaga /
     game_crop_quiz / game_eagle_eye / ladder)
────────────────────────────────────────
  문제:
    - 게임 안의 "🎮 게임센터"(또는 🏠) 버튼이 location.href로 이동 →
      히스토리에 새 항목을 쌓음.
    - 그래서 게임센터로 간 뒤 "뒤로가기"를 누르면 방금 하던 게임으로
      되돌아가서, 두당·PDF센터·텐아르 등 진입처(홈)로 못 나가는 문제.

  변경:
    - "게임센터/홈" 버튼 이동을 다음 방식으로 변경.
        · 게임센터에서 들어온 경우(referrer=game_center) → history.back()
          (게임 항목을 히스토리에서 제거하고 기존 게임센터로 복귀)
        · 그 외(직접 진입 등) → location.replace('game_center.html')
          (게임 항목을 대체, 히스토리에 안 쌓음)
    - 결과: 게임센터에서 뒤로가기 시 게임으로 안 돌아가고,
            진입처(두당 · PDF센터 · 텐아르 홈)로 정상 복귀.
    - 게임 로직·점수·그 외 동작 무변경. 좌측 상단 ‹뒤로 버튼 동작도 그대로.

검증
  - 브라우저 실제 흐름 테스트:
      index(진입처) → 게임센터 → 게임 → [게임센터 버튼] → 게임센터
      → [뒤로가기] → index(홈) 복귀 확인 (게임으로 안 돌아감).
  - KOSIS 카드 번호 ①②③④ 정상 표시 확인.
  - JS 문법 검사 통과(node --check) — 수정 파일 전부.
