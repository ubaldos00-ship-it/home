텐아르(TEN-AR) v260 변경사항
저장: 2026-10-19 06:51 KST

수정 파일: tonghab.html(v159), map_libre.html(v191)
※ 계산식·지도 계산 로직은 변경하지 않았습니다. 현장모드로 넘길 '대상 선택'만 고쳤습니다.

════════════════════════════════════════
「🧭 지도에서 A/B포구 위치(현장모드)」가 '이전 핀'으로 가던 문제 수정
════════════════════════════════════════
증상
  - 통합계산기에서 작물 선택 → 필지주소 핀 찍기 → 비율 입력 →
    「지도에서 위치 다시계산하기」로 지도에서 A/B포구를 새로 찍어 전송한 뒤,
    「🧭 지도에서 A/B포구 위치(현장모드)」를 누르면
    ▶ 방금 찍은(현재) A/B포구가 아니라, 이전에 연결했던 '옛 핀'의
      현장모드가 켜지고, 지금 저장된 자료도 아니었습니다.

원인
  - 현장모드로 넘길 때 통합계산기가 '이전에 지도에서 조사표를 열 때
    기록된 연결핀 정보(tenar_pin_link)'만 읽어 지도에 넘겼습니다.
  - 이 연결핀은 "지도에서 저장핀으로 조사표를 열 때만" 갱신되므로,
    통합계산기에서 시작해 새 핀으로 A/B포구를 찍은 경우에는 갱신되지 않아
    옛 핀 정보가 그대로 넘어가, 지도가 옛 핀의 현장모드를 켰습니다.

수정
  - 통합계산기(tonghab v159):
    현장모드로 갈 때 '지금 조사표에 붙어 있는 지도작업 원본(A/B포구)'의
    고정 식별자(linkId)와 가-지점 좌표를 지도로 넘기도록 변경.
    (현재 조사표에 지도작업이 없을 때만 기존 연결핀 방식 사용)
  - 지도(map_libre v191):
    넘어온 linkId로 저장된 A/B포구(현재 조사표의 그 작업)를 먼저 찾아
    그 포구를 불러와(지도 중심·A/B까지 복원) 현장모드를 시작하도록 변경.
    linkId가 없거나 못 찾을 때만 기존 방식(저장핀 id·주소·좌표 근접)으로.
  → 이제 방금 작업·전송한 현재 A/B포구로 바로 현장모드가 시작됩니다.

검증
  - 통합계산기: 현재 지도작업(linkId+좌표)이 있으면 그 linkId를 넘기고
    옛 연결핀(favoriteId)은 넘기지 않음 확인. 지도작업이 없을 때만
    기존 연결핀 방식으로 폴백함 확인(브라우저 테스트).
  - 지도: consumeGoField가 linkId를 최우선으로 조회(getFpSaves→loadFpSave→
    현장모드)하도록 연결됨 확인. 지도 정상 로드 확인.
  - JS 문법 검사 통과(tonghab 21개·map 4개 인라인 스크립트, node --check).
  - ※ 실제 현장모드(GPS·진행방향) 동작은 실기기에서 한 번 최종 확인 권장.
