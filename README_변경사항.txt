1) 공유 버튼 문제 수정 — 「처음엔 다른 화면, 두 번째에 공유」 현상
════════════════════════════════════════
원인
  - 공유를 누르면 ①암호 입력 → ②암호화(시간이 걸리는 처리)를 거친 뒤에야
    공유를 시도하는데, 그 사이에 아이폰이 "방금 누른 동작"으로 인정하는
    시간이 풀려버려, 바로 공유창이 못 뜨고 복사/다운로드 안내로 빠졌습니다.
    (그래서 한 번 더 누르면 그제서야 공유창이 떴습니다.)

수정
  - 암호 입력·암호화를 끝낸 뒤 「📤 공유 준비 완료」 창을 띄우고,
    거기 「📤 공유하기」 버튼을 누르면 그 순간 바로 공유창(카톡·메시지 등)이
    뜨도록 바꿨습니다. → 폴백으로 빠지지 않고 한 번에 공유됩니다.
  - 공유가 안 되는 기기에서는 「파일로 저장」으로 안전하게 폴백합니다.
  - 적용: 통합계산기 · 청취계산기 · 지도(생산량목록) · 주수(이삭수).

════════════════════════════════════════
2) 조사구(지도) 공유 버튼 추가
════════════════════════════════════════
  - 조사구 저장·불러오기 → 📂 파일 에 「📤 공유」 버튼 추가
    (JSON 가져오기 옆). 현재 보고 있는 조사 종류의 조사구를 공유합니다.
  - 전체 백업·복원 옆에 「📤 전체 공유」 버튼 추가.
    6개 조사 종류(작물재배·가축·축비·농비·쌀값·농판) 전체를 한 번에 공유.
  - 공유 파일도 사용자 암호로 암호화됩니다(9자리 이상·공백 없음 규칙 적용).
  - 통합·청취 공유와 같은 방식(📤 공유하기 버튼)으로 동작합니다.

검증 (브라우저 실제 테스트)
  - 공유 준비 모달: 버튼 누르기 전엔 공유가 실행되지 않고, 「공유하기」
    버튼을 눌러야 그 순간 공유가 실행됨(파일명 정확) 확인 → 폴백 먼저
    뜨던 문제 해결.
  - 공유 미지원 시 파일 저장 폴백 확인.
  - JS 문법 검사 통과(node --check, 4파일).
  - ※ 실제 기기(아이폰)에서 각 공유 버튼이 한 번에 공유창을 띄우는지,
    조사구 공유 버튼이 보이는지 최종 확인 권장.
