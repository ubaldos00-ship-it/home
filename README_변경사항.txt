1) 암호는 9자리 이상이어야 저장됩니다.
   - 9자리 미만이면 저장(내보내기·공유)이 되지 않고, 그 자리에서 다시
     입력하라고 안내합니다.
   - 암호 입력창 안내문에 "암호는 9자리 이상으로 저장하세요" 문구를 넣었습니다.

2) 암호에 공백(띄어쓰기)이 들어가면 저장되지 않습니다.
   - 공백이 포함되면 저장이 막히고, 공백 없이 다시 입력하라고 안내합니다.
   - 안내문에 "공백(띄어쓰기)이 들어가 있으면 저장이 안 됩니다" 문구를
     넣었습니다.

3) 빈칸이거나 취소하면 내보내기가 중단됩니다(기존 v249~ 유지).

(가져오기/불러오기는 그대로)
   - 예전에 만든 파일(짧은 암호·옛 기본암호 2026 등)도 가져오기 때는
     그 암호를 입력하면 정상 복호화됩니다. 길이·공백 검증은 「내보내기」에만
     적용됩니다(기존 파일 호환).

적용 범위(공용 함수 _tenarAskPassword 한 곳 수정 → 전체 적용)
   - 통합계산기 / 청취계산기 : JSON 공유 · 내보내기
   - 지도 : 생산량목록 공유 · 내보내기 / 조사구 JSON 내보내기 · 전체 백업
   - 주수(이삭수 계산기) : JSON 공유 · 내보내기

검증 (브라우저 실제 테스트)

     암호화 저장 확인, 빈칸/취소 → 중단 확인.
   - 옛 파일(암호 2026)도 가져오기 정상 복호화 확인(내보내기 규칙 미적용).
