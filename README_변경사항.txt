1) 조사구 종류에 「기타조사」 추가 (농판 다음, 7번째)
════════════════════════════════════════
  - 지도를 꾹 눌러 나오는 「📍 이 위치에 저장」 시트에
    작물재배·가축·축비·농비·쌀값·농판 다음으로 「📋 기타조사」가 추가됩니다.
  - 조사구목록(🌾) 상단의 종류 선택 탭에도 「📋 기타조사」가 함께 나옵니다.
  - 저장/불러오기·순서안내·핀 색상·전체백업/복원·좌표조회 등 모든 도구가
    종류를 공유하므로 「기타조사」도 자동으로 똑같이 동작합니다.
    (AREA_TYPES 한 곳에 추가 → 전 도구 자동 연동)
  - 핀 모양: ◉ (청록색 #0891b2), 저장키: tenarAreaPlots_etc_enc (자동 암호화)

════════════════════════════════════════
2) 「기타조사」 추가 창 = 농판형 (성명 → 조사구이름)
════════════════════════════════════════
  - 「기타조사」를 고르고 「＋ 추가」를 누르면 추가 폼이 뜹니다.
  - 농판과 똑같이 「이름 칸 + 전화번호」 구조이되,
    「성명」 라벨을 「조사구이름」으로 바꿔 표시합니다. (필수 입력)
  - 필수 입력 안내 문구도 "「조사구이름」은 꼭 입력해 주세요."로 표시됩니다.
  - 전화번호는 자동 하이픈(010-0000-0000 등) 그대로 적용.

검증 (브라우저 실제 테스트)
  - 저장 시트·조사구목록 탭에 7종(작물재배·가축·축비·농비·쌀값·농판·기타조사)
    모두 표시, 「기타조사」가 농판 다음에 위치 확인.
  - 「기타조사」 추가 폼 라벨 = 「조사구이름 ＊필수」 + 「전화번호」 (축종/지목 칸 없음) 확인.
  - 인라인 스크립트 JS 문법 검사 통과(4블록).
